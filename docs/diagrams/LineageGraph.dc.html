GET /v1/lineage/{model}/{version}/ancestorsFrom the current node: everything it descends from. For node 4 that is nodes 1 to 3.
GET /v1/lineage/{model}/{version}/blast-radiusFrom the current node: everything downstream of it. Empty for the newest node, as in the demo run.
