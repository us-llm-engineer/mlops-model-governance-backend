11 · MLflow mirror

A shadow copy, never the source of truth

Off unless mlflow_tracking_uri is set. The domain registry stays authoritative either way.

1. Settingmlflow_tracking_uri must be an absolute sqlite:/// URI. Default None: no bridge, no mlflow import.
▼ create_app
2. MlflowBridge(uri)Owns its own client; never touches MLflow's global tracking URI, so two bridges cannot redirect each other.
▼ every register, validate, transition
3. mirror_experiment_runParams artifact_hash and dataset_version, run id model:version, experiment named after the model. Repeat calls reuse the same run.
▼ only if version_id is all digits
4. mirror_stage_transitionSets an MLflow model alias for the stage. Operator-chosen ids like "v1" skip this step instead of failing.
▼ any exception
5. SwallowedA mirror failure never blocks or changes the real registration.
Traps the bridge already handles
File store is deprecated in mlflow-skinny 3.16: only sqlite URIs are accepted.
Params are stored as strings; private type tags restore ints, floats and bools on read.
Stages are deprecated; aliases are used instead.
Version numbers are allocated by MLflow. Asking for a number it would not assign raises Conflict before anything is created: no junk versions, no silent misalignment.
Read it backbridge.get_mirrored_run("model:version") returns params, latest metrics and tags. The demo prints it.
